# 해짤방 유튜브 채널 꾸미기

## 1. 이미지 (YouTube Studio → 맞춤설정 → 브랜딩)
| 항목 | 파일 | 규격 |
|---|---|---|
| 프로필 사진 | `profile_800x800.png` | 800×800, 원형으로 잘려도 안전 |
| 배너 이미지 | `banner_2560x1440.png` | 2560×1440, 핵심 내용은 모바일 안전영역(1546×423) 안 |

수정: `src/profile.html`, `src/banner.html` 편집 후 `node src/render.cjs`

## 4. 영상 제목 / 태그 템플릿
- 제목: `[해짤방] 보고도 믿기지 않는 해외 영상 TOP 10 🤯`
- 제목: `해외에서 난리난 웃긴 영상 모음 😂 #3`
- 고정 해시태그: `#해짤방 #웃긴영상 #신기한영상`

## 5. 썸네일 통일 규칙
- 배경 포인트 컬러: 파랑 `#3D7BFF` / 노랑 `#FFD23F` / 빨강 `#FF5A3C`
- 글씨: 굵은 고딕(Black Han Sans) + 검정 외곽선
- 오른쪽 아래에 선글라스 해 캐릭터를 작게 넣어 브랜드처럼 반복 사용

## 6. 꼭 챙길 것 (짜깁기 채널 주의사항)
- 다른 사람 영상을 그대로 이어 붙이기만 하면 **수익 창출 심사에서 '재사용 콘텐츠'로 거절**될 수 있어요.
  → 자막, 나레이션, 순위 매기기, 리액션, 해설 같은 **나만의 편집과 해설을 꼭 추가**하세요.
- 원본 출처(채널명) 표기를 권장합니다. 저작권 신고가 들어오면 바로 내리세요.
