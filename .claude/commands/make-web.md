# /make-web 작업 매뉴얼

입력: $ARGUMENTS

## 1단계: 기획 → `web_plan.md` (컨펌 필수)
요구사항을 분석해 아래 내용을 `web_plan.md`로 작성하고, 사용자 승인을 받기 전에는 코드를 생성하지 않는다.
- 사이트 목적과 타깃
- 홈페이지 메뉴 구조(사이트맵)
- 페이지별 주요 섹션
- 디자인 컨셉(컬러, 폰트, 무드, 레퍼런스)

## 2단계: 개발 (승인 후)
- 설치할 패키지와 작업 계획을 먼저 브리핑한다.
- Next.js + Tailwind CSS 기반으로 PC/모바일 반응형 웹사이트 코드를 생성한다.
- 로컬 테스트 서버(`npm run dev`)를 띄우고 접속 주소를 안내한다.
