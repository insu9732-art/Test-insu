# /yt-blog 작업 매뉴얼

입력: $ARGUMENTS

각 단계가 끝날 때마다 파일을 저장하고, 결과 요약을 짧게 보고한 뒤 다음 단계로 넘어간다.

## 1단계: 분석 → `1_analysis.md`
입력받은 주제나 레퍼런스 대본을 분석해 저장한다.
- 핵심 주제와 메시지
- 타깃 시청자
- 레퍼런스의 구조와 후킹 포인트(대본 입력 시)
- 차별화 아이디어

## 2단계: 쇼츠 대본 → `2_shorts_script.md`
초반 3초 후킹이 포함된 쇼츠 대본과 씬별 영문 이미지 생성 프롬프트를 표 형태로 작성해 저장한다.

| 씬 | 시간 | 대본(나레이션) | 영문 이미지/영상 프롬프트 |
|---|---|---|---|
| 1 (Hook) | 0~3초 | ... | ... |
| 2 | 3~10초 | ... | ... |

- 1번 씬은 반드시 3초 안에 시선을 잡는 후킹 문장으로 시작한다.
- 문장마다 이미지/영상 프롬프트를 세트로 작성한다.

## 3단계: 블로그 원고 → `3_blog_post.md`
위 대본을 바탕으로 구글/네이버 SEO에 맞춘 블로그 포스팅 원고로 변환해 저장한다.
- 제목: 핵심 키워드 포함, 클릭을 부르는 형태
- 소제목: H2/H3 구조
- 본문: 키워드를 자연스럽게 배치, 가독성 높은 짧은 문단
- 태그: 관련 키워드 10개 내외
