# 내 편집 스킬

## 절대 규칙 (내가 준 피드백, 날짜순으로 계속 추가)
- 화면은 실제 사이트 캡처·실제 실행 녹화만. 목업 카드·가짜 터미널 금지.
- 맨 위 제목은 첫 화면부터 고정. 흐릿하게 나타나지 않게.
- 자막은 단어가 나오는 순간에 하나씩. 강조 단어는 주황색.
- 한 화면을 1.5초 넘게 가만히 두지 않기(줌·하이라이트·칩 등장).
- 2026-11-11: "문장마다 말하는 사이트를 실제로 열어서 캡처해 줘. 강조할 문구의 위치(좌표)도 같은 실행에서 같이 뽑아 줘. 목업이나 가짜 화면은 만들지 마."
- 2026-11-11: "렌더가 끝나면 사람한테 보여주기 전에 꼭 검사해 줘.
  1) 입 모양 싱크: 영상 속 소리와 원본 음성 파일의 시차가 0ms인지
  2) 개인 정보: 0.5초마다 한 장씩 화면 글자를 읽어서 이메일·API 키·계정 ID(UUID)가 보이면 실패
  3) 소리 크기: -14 LUFS(유튜브·인스타 기준)인지
  하나라도 실패하면 고치고 다시 렌더해."
- 2026-11-11~12 (상식숏츠): "필재 일반으로" — 내레이션은 타입캐스트 필재(Piljae), 감정 normal, 속도 1.2배.
- 2026-11-11~12: "영상을 좀더 3d 입체감 있게 만들어 줄수 있어?" — script-to-motion 스킬 + three.js 실제 3D, 카메라 구도(샷 크기·앵글·무빙) 적용.
- 2026-11-11~12: "영상이. 중간에 끊기고 멈추고 대본이랑 앵글도. 좀안맞아" / "대본이랑 영상 잘맛추고 영상 안끌기게 해죠 검수까지꼭해죠"
  → 컷은 문장 경계에서만, 샷 안에서는 느린 카메라 이동 하나가 그 문장의 핵심 단어에 도착. 빠른 휙 돌리기 금지.
  → 검사에 끊김 검사 추가: 프레임 차이로 멈춤(0.5초 이상 정지)·덜컹(HITCH)·급격한 화면 변화가 문장 컷 말고는 없어야 통과.
- 2026-11-11~12: "대본은? 사실기반 검증까지함? 100만터질 대본으로 각색함?"
  → 대본의 사실은 위키백과 + 한국민족문화대백과 두 곳 이상에서 교차검증(대본_검증.txt에 출처 기록). 한 곳만 있는 사실은 표시하고, 단정은 피함.
  → 첫 3초 강한 훅, 궁금증을 남기는 전개, 마지막 댓글 유도 질문. 대본과 출처를 먼저 보여주고 승인받은 뒤 제작.

  → 문장마다 말 그대로의 장면(인물·행동 포함)을 보여줄 것. 상징적·추상적 화면으로 때우지 않기. 렌더 후 캡처 시트로 문장-장면 대응 확인.
- 2026-11-12: "썸네일이미지 만들고 설명란 파일 텍스트로만들고"
  → 방마다 썸네일(1080x1920) + 설명란.txt(유튜브·네이버 클립·틱톡·인스타 제목·설명·태그·고정 댓글) + 업로드정보.txt.
- 2026-11-12: "영상 용량 커도됨" — 화질 우선, 파일 크기 때문에 압축률을 올리지 않음.

## 순서
1. Whisper로 단어마다 시각 받아쓰기 → words.json
2. 쉼 0.18초 초과분은 0.12초만 남기고 자르기(목소리 속도 유지)
3. 문장마다 실제 사이트 캡처 + 강조 문구 좌표(같은 실행에서)
4. /hyperframes 로 1080x1920 조립, words.json 시각에 맞춰 자막·하이라이트
5. 렌더 후 -14 LUFS로 맞추기
6. 검사: 입 모양 시차 0ms · 화면 개인 정보 0건 · -14 LUFS(±0.2) · 끊김/멈춤 없음 · 문장-장면 대응. 실패하면 고치고 다시 렌더

## 상식숏츠 순서 (3D)
1. 주제 → 위키백과 + 한국민족문화대백과로 사실 교차검증 → 훅 있는 대본 → 사용자 승인
2. 타입캐스트 필재 normal 1.2배 TTS → Whisper 단어 시각 → 쉼 자르기(0.18초 초과 → 0.12초)
3. script-to-motion 프로젝트에 내레이션·단어 시각 주입, three.js로 문장마다 말 그대로의 3D 장면
4. 렌더 전 캡처 시트로 구도·대응 확인 → 1080p 30fps 렌더
5. 음량: 2단계 loudnorm → volume → alimiter(latency=1, 싱크 0ms 유지)로 -14 LUFS
6. 검사(위 6번) 통과 → 상식숏츠/N번방/에 영상·썸네일·설명란.txt·업로드정보.txt·대본·검증 저장 → 커밋·푸시

## 도구 설치

### 1) 영상 편집 기본 도구
```bash
brew install ffmpeg tesseract tesseract-lang
pip install openai-whisper
```
- `ffmpeg`: 자르기·합치기·인코딩, `loudnorm`으로 LUFS 측정/보정
- `tesseract` + `tesseract-lang`: 화면 글자 읽기(개인 정보 검사)
- `openai-whisper`: 단어별 시각 받아쓰기

### 2) HTML로 영상을 만드는 HyperFrames (클로드 코드 플러그인, 공식 README 명령)
```bash
claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes
```
