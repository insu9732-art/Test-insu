[상식숏츠 채널 셋팅 지침 — 이대로 붙여넣기]

■ 채널 정체성
- 주제: 한국·세계의 옛 과학과 생활의 지혜를 1분 안에 풀어 주는 역사 상식 쇼츠
- 핵심 메시지: "옛사람들은 기계 없이 이걸 해냈다"
- 대상: 10~40대 일반 시청자, 역사·과학 상식을 좋아하는 사람, 학생과 학부모
- 말투: 친근한 존댓말, 짧은 문장, 첫 문장은 질문이나 놀라운 사실로 시작, 마지막은 댓글 질문
- 형식: 세로 1080x1920, 30~40초, 내레이션 1명(차분한 남성 톤), 단어별 자막(강조어 주황)

■ 그림체 (모든 영상 통일)
- 납작한 2D 콩머리 캐릭터 + 색이 진한 3D 세계 + 가는 검은 잉크선
- 캐릭터: 머리 크고 무표정한 눈, 자줏빛 검정 테두리, 볼터치 없음
- 낮은 파란 하늘·밝은 색, 해 질 녘은 복숭아빛, 가까운 장면은 배경 흐림
- 썸네일: 크림색 배경 + 위쪽 검정 1줄 + 주황 1줄 큰 제목 + 가운데 장면 이미지 + 아래 주황 띠 문구 + 왼쪽 위 "상식숏츠 #번호"

■ 채널 이름 후보 (하나 고르기)
1. 상식숏츠
2. 옛날과학 1분
3. 조상님 과학
4. 역사 속 과학 한입
5. 그때 그 기술

■ 채널 소개 (복붙)
냉장고도 없던 조선에서 한여름에 얼음을 꺼냈다고?
옛사람들이 기계 없이 해낸 놀라운 과학과 지혜를 1분 안에 보여드립니다.
모든 내용은 위키백과·한국민족문화대백과사전 등 두 곳 이상에서 확인한 사실만 다룹니다.
매주 새로운 상식 쇼츠가 올라와요. 구독하고 같이 알아봐요!

■ 채널 키워드 / 태그
역사 상식, 한국사, 조선, 전통과학, 옛날 과학, 조상의 지혜, 1분 상식, 쇼츠, 문화유산, 세계사, 과학 상식, 역사 쇼츠

■ 프로필·배너
- 프로필: 콩머리 캐릭터(갓 쓴 조선 관리) 얼굴 + 주황 원 배경
- 배너 문구: "기계 없이 해낸 옛사람들의 과학 | 매주 1분 상식"
- 배너 그림: 석빙고·온돌·석굴암·측우기 장면을 같은 그림체로 나란히

■ 재생목록
1. 조선의 과학 (석빙고, 측우기, 온돌 …)
2. 신라·고대의 기술 (석굴암, 불국사, 첨성대, 고인돌 …)
3. 세계의 옛 과학 (로마 콘크리트, 그리스의 불, 안티키테라 …)
4. 전체 상식숏츠 (번호순)

■ 지금까지 만든 영상 (업로드 순서)
#1 석빙고 — 제목: 한여름, 죄수에게도 얼음을 줬다?! (조선의 석빙고)
#2 온돌   — 제목: 불 한 번 때면 한 달 따뜻?! (온돌의 비밀)
#3 석굴암 — 제목: 천 년 버틴 석굴암, 고치자 물이 샜다?! (신라의 비밀)
#4 측우기 — 제목: 측우기 하면 장영실? 실록엔 다른 이름이?! (실록 속 세자)
#5 고인돌 — 대본 준비 중: 크레인 없이 수십 톤 바위를 어떻게?
다음 주제 순서: 한지 → 불국사 그렝이법 → 판옥선 → 거중기 → 해인사 장경판전 → 첨성대 …(총 30개)

■ 제목 공식
[놀라운 사실 / 반전 질문] + ?! + #shorts
예) 냉장고도 없던 조선, 한여름에 얼음을? #shorts

■ 설명란 공식
1줄: 훅 문장
2~5줄: 원리를 이모지 4단계로 (🔥 → 💨 → 🪨 → 🌙 처럼)
출처 줄: 📚 출처: 한국민족문화대백과사전 「항목」, 위키백과 「항목」
질문 줄: 👉 여러분은 ~? 댓글로!
해시태그 3~6개

■ 고정 댓글 공식
영상 마지막 질문을 그대로, 선택지 2개로 (예: 아랫목파 vs 윗목파)

■ 업로드 운영
- 주기: 주 3회 (월·수·금 저녁 6~8시)
- 플랫폼: 유튜브 쇼츠 / 네이버 클립 / 틱톡 / 인스타 릴스에 같은 영상
- 플랫폼별 제목·설명·태그는 각 방 폴더의 설명란.txt 사용
- 소리: -14 LUFS, 싱크 0ms, 화면 개인정보 0건 검수 후 업로드

■ 지킬 규칙
- 사실은 두 곳 이상에서 교차검증, 한 곳만 있는 내용은 "~라고 봅니다"로 추정 표현
- 대본과 화면은 말 그대로 일치 (죄수에게 얼음 → 죄수에게 얼음 주는 장면)
- 캐릭터·배경·이야기는 전부 우리 것으로 새로 그림, 다른 채널 영상·이름 사용 금지
- 실존 인물·기관 사칭, 가짜 기록 금지
