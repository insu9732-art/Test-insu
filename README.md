# 사주풀이 (모바일 웹앱)

휴대폰에서 바로 쓰는 사주팔자 풀이 앱입니다. 설치 없이 브라우저로 열고, **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다(PWA, 오프라인 지원).

## 기능

- **사주 원국**: 연·월·일·시주 8글자와 십신(비견·식신·정관 …)
- **오행 분석**: 목·화·토·금·수 분포, 부족/과다 진단, 신강·신약, 도움이 되는 기운(행운 색·방향·숫자)
- **성격 풀이**: 일간(10가지) 성격, 사회적 성향(월지), 배우자 자리(일지)
- **대운**: 순행/역행, 대운수, 10년 단위 대운과 현재 대운 풀이
- **운세**: 오늘의 일진 운세(별점), 올해 세운
- 양력/음력(윤달) 입력, 시간 모름 지원, 서울 기준 시차 보정(−30분), 1987·88년 서머타임 자동 반영
- 사주 저장(기기 내 저장) · 공유

## 실행

빌드 과정이 없는 순수 HTML/JS입니다.

```bash
npm start        # http://localhost:8080 (또는 아무 정적 서버)
npm test         # 계산 엔진 테스트
```

휴대폰에서 쓰려면 GitHub Pages·Netlify 등 HTTPS 정적 호스팅에 이 폴더를 그대로 올린 뒤,
- iPhone(Safari): 공유 → **홈 화면에 추가**
- Android(Chrome): 메뉴 → **앱 설치 / 홈 화면에 추가**

## 계산 방식

| 항목 | 기준 |
| --- | --- |
| 연주 | 입춘(태양 황경 315°) 기준으로 해가 바뀜 |
| 월주 | 12절(節) 기준, 연간에 따른 월두법 |
| 일주 | 1900-01-01 = 甲戌일 기준 60갑자 순환 |
| 시주 | 일간 기준 시두법, 23시부터 다음 날 子시 |
| 대운 | 양년생 남/음년생 여 순행, 절입까지 일수 ÷ 3 = 대운수 |
| 음력 | 브라우저 내장 한국 음력(`dangi`) 달력으로 변환 |

절입 시각은 천문 근사식(Meeus)으로 계산해 실제와 수십 분 이내 차이가 날 수 있습니다. 절입 직전·직후 출생이면 만세력으로 한 번 더 확인하세요. 1950년대 등 과거 표준시 변경·서머타임은 반영하지 않았습니다.

> 재미와 참고용입니다. 중요한 결정은 스스로의 판단으로 하세요.
